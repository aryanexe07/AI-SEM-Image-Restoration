# Qualitative Failure Analysis Report: exp001_nafnet_baseline

## Overview

This report documents the qualitative failure analysis workflow for SEM (Scanning Electron Microscope) image noise reduction and 2× super-resolution, established in accordance with domain inspection recommendations (e.g. KLA webinar guidance). Rather than relying exclusively on aggregate full-reference metrics (PSNR, SSIM, LPIPS), this qualitative evaluation framework inspects restored micrographs directly for structural fidelity, high-frequency edge definition, noise suppression performance, and potential restoration artifacts.

Following strict evaluation integrity guidelines, this report evaluates real dataset samples from the SEM restoration benchmark and documents verified baseline observations.

## Evaluation Method

1. **Visual Panel Standardization**:
   - Comparison grids render aligned 4-panel figures:
     1. **Raw Noisy Input**: Degraded low-resolution SEM micrograph (128×128 spatial resolution aligned to 256×256 target size via aspect-ratio preserving interpolation).
     2. **Ground Truth**: High-resolution reference SEM micrograph (256×256 target resolution).
     3. **Baseline NAFNet Output**: Output generated by the `exp001` baseline NAFNet model.
     4. **Improved Model Output**: Output from the improved restoration model (Issue #38).
   - An optional 5th reference column (**Bicubic Reference**) may be rendered for interpolation baseline comparison, explicitly separated from neural model outputs.

2. **Strict Intensity Normalization**:
   - All primary comparison panels enforce a uniform, fixed intensity mapping:
     $$\text{Pixel Intensity} \in [0.0, 1.0] \rightarrow \text{Display Range}$$
   - Independent panel percentile scaling, dynamic histogram equalization, and cross-panel contrast matching are strictly prohibited to prevent visual misrepresentation of restoration quality.

3. **Crop & Zoom Inspection**:
   - Secondary diagnostic grid artifacts are generated at fixed bounding box coordinates `[64:192, 64:192]` to inspect fine nanometer-scale structures, edge sharpness, oversmoothing, and potential boundary/tile artifacts.

4. **Reproducibility**:
   - Sample selection is governed deterministically using a fixed random seed (`seed = 42`).
   - Generation parameters, crop coordinates, source file paths, and execution timestamps are logged per evaluation run.

## Baseline Observations

1. **Checkpoint Availability**:
   - As documented in `experiments/exp001_baseline_report.md`, the `exp001` Kaggle baseline training run achieved +6.5049 dB validation PSNR improvement (29.4118 dB vs 22.9069 dB raw baseline), but trained `.pth` weight artifacts were not saved in workspace directory `outputs/checkpoints/`.
   - To preserve scientific integrity, uninitialized NAFNet weights and bicubic interpolations are **never** labeled or masqueraded as `exp001 Baseline NAFNet` outputs.

2. **Raw Input vs Ground Truth Characteristics**:
   - Inspection of raw SEM inputs confirms significant Poisson-Gaussian shot noise and lower spatial contrast relative to Ground Truth.
   - Bicubic spatial upscaling of raw input improves image dimensions (128×128 → 256×256) but fails to eliminate high-frequency noise or restore sharp nanoscale edge boundaries.
